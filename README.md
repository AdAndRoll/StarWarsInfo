# Star Wars Info 🌌

Android-приложение для глубокого изучения вселенной Star Wars. Это не просто справочник, а полноценная база данных с перекрестными ссылками между персонажами, планетами и фильмами, работающая по принципу **Offline-first**.

## 🚀 Основные возможности

* **Экосистема персонажей**: Просмотр детальной информации (рост, масса, пол) с поддержкой полного кэширования.
* **Интерактивная графовая навигация**:
    * Из карточки персонажа — переход на **страницу планеты** (Homeworld) или **страницу фильма**.
    * Со страницы планеты — просмотр **списка всех её жителей**.
    * Со страницы фильма — переход к **списку всех героев**, участвовавших в нём.
* **Умный Кэш (RemoteMediator)**: Приложение приоритетно отображает данные из БД Room, подгружая новые страницы из сети только при необходимости.
* **Бесшовная пагинация**: Списки подгружаются по мере скролла без мерцаний и прыжков контента за счет стабильных ключей и оптимизированной сортировки.

## 🛠 Технический стек

* **UI**: Jetpack Compose (Declarative UI)
* **Architecture**: Clean Architecture + MVVM
* **DI**: Dagger Hilt
* **Database**: Room (сложные связи, транзакции, поддержка пагинации)
* **Network**: Retrofit 2 + OkHttp + Paging 3
* **Async**: Kotlin Coroutines & Flow

## 🏗 Архитектурные решения

Проект разделен на независимые слои для обеспечения тестируемости и гибкости:
1.  **Domain Layer**: Чистые сущности (`SWCharacter`, `SWPlanet`, `SWFilm`) и UseCases для бизнес-логики (например, `GetCharacterDetailsUseCase`).
2.  **Data Layer**: Репозитории, мапперы, API-сервисы и `RemoteMediator` для синхронизации сети и локального хранилища.
3.  **Presentation Layer**: ViewModels с использованием `StateFlow` и UI-компоненты на Compose.
